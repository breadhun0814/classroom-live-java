# Classroom Live 포트폴리오 사이트

공개 주소: [Classroom Live 포트폴리오](https://breadhun0814.github.io/classroom-live-java/)

## 구성

- `index.html`: 프로젝트 소개, 실제 앱 화면, 사용 흐름, 브라우저 예시 체험, 기술 설계, 검증, 설치 링크.
- `portfolio.css`: 밝은 배경과 청록색을 사용한 반응형 디자인. 사용자의 Careflow 포트폴리오 구성을 참고했습니다.
- `portfolio.js`: 기능 탭, 로컬 채팅 예시, 설정 프리셋, 예시 이용 정지·복구, 코드 복사, 경로 설명, 이미지 확대, 모바일 메뉴.
- `START_HERE.html`: 기존 5개 언어 설치 안내. 서버의 실제 앱은 `public/`에 있습니다.
- `.nojekyll`: 저장소 루트의 정적 파일을 GitHub Pages에서 그대로 제공합니다.

프레임워크나 외부 CDN 없이 HTML·CSS·JavaScript로 실행합니다. 이 사이트의 체험에는 실제 계정·로그인·영상 전송이 없고, 입력 내용은 브라우저 메모리에만 남습니다. 실제 교실 서비스는 기존 Java 서버에서 실행합니다.

## 배포

이 저장소의 GitHub Pages는 `main` 루트에서 배포합니다. 사이트 파일을 수정해 `main`에 반영하면 Pages 배포가 진행됩니다. 배포 완료 후 [공개 주소](https://breadhun0814.github.io/classroom-live-java/)에서 새 내용을 확인합니다.

설치 안내 동기화 도구는 `START_HERE.html`을 원본으로 사용합니다. `node scripts/sync-guides.cjs`가 포트폴리오 `index.html`을 설치 안내로 덮어쓰거나 서버 도움말에 복사하지 않도록 분리했습니다.

## 2026-11-27 사이트 검증

Windows의 실제 Edge 자동화로 다음 항목을 확인했습니다.

- HTTP 응답, HTML의 단일 주제 제목, 로컬 이미지·CSS·JS 경로, 내부 섹션 링크.
- 실제 화면 확대와 Escape 닫기, 코드 복사, 기능 탭과 키보드 탐색.
- 예시 채팅 전송·초기화. HTML 태그 입력이 실행되지 않고 텍스트로 표시되는지 확인.
- 화질 프리셋 설명, 예시 이용 정지·복구, 기술 경로 설명, 설계 문답 펼치기.
- 390px·768px·1024px·1440px 화면 구성, 가로 넘침, 모바일 메뉴 열기·이동·닫기.
- 설치 안내의 영어 전환과 11개 안내 항목, 기존 jsdom 기반 5개 언어 가이드 테스트.

로컬 브라우저 검사 19개 항목이 통과했고, 자바스크립트 오류와 페이지 초기 로딩의 외부 요청이 없었습니다. 화면 캡처를 직접 열어 PC·모바일 레이아웃을 확인했습니다. 외부 GitHub·Careflow 링크를 방문하면 해당 서비스에 접속합니다.

기존 Java 서버와 WebRTC 미디어 구현은 변경하지 않았습니다. 실제 여러 PC의 영상 품질과 장시간 사용 검증 범위는 [기존 검증 기록](VERIFICATION_2026-11-27.md)을 참고하세요.
