# 블루 테마 반응형 화면 점검

점검일: 2026년 11월 27일. GitHub Pages 공개 사이트를 브라우저에서 직접 살펴본 뒤, 로컬 미리보기에서 수정 결과를 확인했습니다.

## PC 화면

- 1440×1000 화면에서 첫 화면, 사용 흐름, 예시 체험, 기술 설계, 검증, 다운로드, 하단 링크와 설치 안내 전체를 스크롤하며 확인했습니다.
- 1024×900의 작은 PC 화면에서도 체험 패널과 대화창 배치를 확인했습니다.
- 어두운 체험 입력칸의 예시 문자를 밝게 바꾸고, 대화 본문과 주요 설명을 16px로 조정했습니다.
- 초기 대화 3개가 잘려 보이지 않도록 높이를 조정하고, 메시지가 많아질 때는 내부 스크롤을 사용합니다.
- 영상 경로 선택 시 서버 글씨를 흐리게 만드는 대신 점선 상자로 구분하고, 영상 송수신 브라우저를 강조했습니다.
- 설치 파일 이름이 하이픈 중간에서 끊기지 않도록 처리했습니다.

## 모바일 화면

- 390×844 화면에서 첫 화면부터 하단까지, 설치 안내의 서버·학생 단계와 FAQ까지 확인했습니다.
- 320px 폭에서 제목, 메뉴, 설치 순서, 파일명과 확대 창을 추가 점검했습니다. 360px·430px 폭의 가로 넘침과 대화창 크기, 768×1024 태블릿 화면 배치도 확인했습니다.
- 모바일 제목을 화면 폭에 따라 조정하고 주요 버튼을 세로로 배치해 어색한 줄바꿈을 줄였습니다.
- 작은 화면의 기능 카드는 한 열로 표시하며, 메뉴·체험 제어·관리자·닫기 버튼의 최소 높이는 44px입니다.
- 채팅 입력 글자를 16px로 키우고 안내 문구를 짧게 했습니다. 채팅 위치를 "오른쪽"으로 지칭하던 설명을 화면 배치와 무관한 표현으로 바꿨습니다.
- 설치 페이지 상단 안내 링크와 확대 창의 닫기 버튼이 좁은 화면에서 어색하게 나뉘지 않도록 조정했습니다.
- 확인한 폭에서 페이지 전체 가로 넘침은 없었습니다.

## 동작·패키지 검증

- 브라우저: 예시 방 값 채우기·입장 확인, 코드 채팅 전송, 관리자 이용 정지 표시, 체험 초기화, 경로 전환, 모바일 메뉴, 이미지 확대·닫기, 설치 FAQ 펼침을 확인했습니다.
- `node tests/portfolio.test.cjs`: 통과. 오류/성공 입장, 코드 복사와 실패 대체 동작, 메시지 제한 뒤 초기화, IME 입력, 문자열 안전성, 로컬 링크와 ZIP 자원 확인.
- `node tests/guides.test.cjs`: 통과. 5개 언어 안내와 링크·언어 전환 확인.
- 실행 ZIP을 다시 생성했으며, 29개 파일이 현재 소스 파일과 일치하고 데이터·개인 인증서·다운로드한 JDK·개발 소스가 제외되는지 확인했습니다.

## 점검 범위

모바일 확인은 데스크톱 브라우저의 화면 크기 조절을 이용했습니다. 실제 iOS Safari·Android 기기에서의 터치·키보드·브라우저별 렌더링 검증을 의미하지 않습니다. 이번 수정은 포트폴리오와 설치 안내의 화면 개선이며 실제 교실 영상 성능 검증은 포함하지 않습니다.
