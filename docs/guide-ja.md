# Classroom Live Java LAN — 日本語

[한국어](guide-ko.md) | [English](guide-en.md) | [日本語](guide-ja.md) | [简体中文](guide-zh-CN.md) | [Tiếng Việt](guide-vi.md)

教室のパソコン1台でログイン・チャット・画面共有を運用できます。

> このページは導入ガイドです。授業には教室サーバーを起動し、https://サーバーIP:ポート/ に接続してください。GitHub PagesではJavaサーバーは動作しません。

## できること

教員を含め1部屋最大8接続、同時に1人が画面共有できます。ID・パスワード登録、パスワード付きルーム、文章・コードのチャット、管理者による利用者管理、高画質の画面共有を備えています。アカウントとチャットは教室サーバーに保存し、画面は録画しません。音声共有・添付ファイルは含みません。

## 1. サーバーPCの準備

GitHubのCode → Download ZIPで取得し、すべて展開します。ClassroomLive.jarと00-Java-Check.cmdがあるフォルダーを開いてください。サーバーにはJava 17以上とkeytoolが必要です。Python・Maven・クラウド登録は不要です。学生PCはChromeのみ使用します。

## 2. Spring ToolsのJavaを指定

00-Java-Check.cmdを実行します。Javaが見つからない場合は、Spring Tools → Window → Preferences → Java → Installed JREs → EditのJRE homeをコピーします。JARの隣にjava-path.txtを作り、1行目に実際のJDKフォルダーを保存して再確認します。例のパスをそのまま使わないでください。

## 3. 初回設定

PowerShellでipconfigを実行し、有線Ethernetの実際のIPv4とサブネットマスクを確認します。01-Setup.cmdでサーバーIP、許可するネットワーク、ポート（標準8443）、管理者IDと12文字以上のパスワードを設定します。例：IPが192.168.22.156、マスクが255.255.255.0ならネットワークは192.168.22.0/24です。実際の値に置き換えてください。

## 4. ファイアウォールと起動

サーバーPCで03-Firewall.cmdを右クリック → 管理者として実行。指定した教室ネットワークから接続ポートだけを許可します。02-Start.cmdを実行し、授業中はウィンドウと電源を維持してください。終了はCtrl+Cです。ファイアウォール全体を無効にしないでください。

## 5. 学生PCの接続準備

生成されたdata/STUDENT_SETUP.zipだけを学生に配布します。サーバー利用者を含む各Windows利用者が展開し、Setup.cmdを実行します。教員から受け取った正規のファイルと確認してYESを入力し、教室証明書の登録を承認します。Chromeを完全終了して開き直してください。サーバーフォルダー全体やdata/tlsは配布しません。学校の制限がある場合は担当者に依頼します。

## 6. 登録・入室・授業

サーバーに表示されたHTTPSアドレスをChromeで開きます。学生はID、8文字以上のパスワード、表示名で登録します。メール認証はありません。教員は設定した管理者アカウントでログインし、チャット画面に戻ってパスワード付きルームを作ります。学生は部屋を選び、部屋のパスワードで入室します。Enterで送信、Shift+Enterで改行。コードはコード形式を選びます。

## 7. 画質と言語

共有側で「授業の文字を鮮明に」を選ぶと、元の解像度・高画質・30fpsになります。「動画を滑らかに」は1080p・60fps・H.264優先です。実際の画質とFPSはPCとネットワークに依存します。視聴側は全画面・元のサイズ表示を利用できます。言語設定は画面の案内とボタンに適用され、ブラウザーに保存されます。

## 8. 管理・バックアップ・更新

指定された管理者だけが利用者一覧、停止・解除、部屋からの退室、部屋の削除を操作できます。管理者本人は停止できません。04-Backup.cmdと05-Reset-Password.cmdはサーバー終了後に実行します。更新は停止 → ClassroomLive.jarを置換 → dataとjava-path.txtを保持 → 再起動 → 全員Ctrl+Shift+Rです。再起動後は再ログイン・再入室が必要です。

## 接続や画質の問題

電源、実際のIP、ポート、許可ネットワーク、証明書登録を確認します。チャットだけ使える場合はChromeを更新し、接続診断をコピーしてください。同じ建物でもVLANや端末分離で映像が遮断される場合があり、学校担当者の許可が必要です。同じサブネット内の有線とWi-FiをIP制限だけでは区別できません。7人への高画質送信は共有PCの負荷を増やします。1080pの元画面を1440pにしても元にない細部は増えません。

## GitHubへ公開

新しいリポジトリでAdd file → Upload filesを選び、展開した内容をアップロードします。README.mdを最上位に置くと説明が表示されます。生成されたdata、証明書の秘密鍵、会員情報、個人用java-path.txtは公開しないでください。ブラウザーでのアップロードは.gitignoreで自動除外されません。案内サイトはSettings → Pages → Deploy from a branch → main / (root)で設定します。
