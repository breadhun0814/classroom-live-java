# Classroom Live Java LAN — 한국어

[한국어](guide-ko.md) | [English](guide-en.md) | [日本語](guide-ja.md) | [简体中文](guide-zh-CN.md) | [Tiếng Việt](guide-vi.md)

교실 컴퓨터 한 대로 로그인·채팅·화면 공유를 운영하세요.

> 이 페이지는 설치·사용 안내입니다. 실제 수업은 교실 서버를 켠 뒤 https://서버IP:포트/로 접속합니다. GitHub Pages는 Java 서버를 실행하지 않습니다.

## 어떤 프로그램인가요?

교수님 포함 한 방에 최대 8접속, 동시에 한 명이 화면을 공유합니다. 아이디·비밀번호 가입, 비밀번호 방, 텍스트·코드 채팅, 관리자 회원 관리, 고화질 화면 공유를 제공합니다. 계정과 채팅은 교실 서버에 저장하며 화면은 녹화하지 않습니다. 음성 공유와 파일 첨부는 포함하지 않습니다.

## 1. 서버 PC 준비

GitHub에서 Code → Download ZIP → 모두 압축 풀기를 선택하세요. ClassroomLive.jar와 00-Java-Check.cmd가 보이는 폴더에서 작업합니다. 서버 PC에는 Java 17 이상과 keytool이 필요합니다. Python·Maven·외부 클라우드는 필요 없습니다. 학생 PC에는 Chrome만 있으면 됩니다.

## 2. Spring Tools의 Java 연결

00-Java-Check.cmd를 실행합니다. Java를 못 찾으면 Spring Tools → Window → Preferences → Java → Installed JREs → Edit에서 JRE home을 복사하세요. 프로그램 폴더에 java-path.txt를 만들고 첫 줄에 실제 JDK 폴더 경로를 저장한 뒤 다시 확인하세요. 예시 경로를 그대로 쓰지 마세요.

## 3. 최초 서버 설정

PowerShell에서 ipconfig를 입력해 랜선 이더넷의 실제 IPv4와 마스크를 확인하세요. 01-Setup.cmd 실행 → 실제 서버 IP → 허용 대역 → 포트(기본 8443) → 관리자 아이디와 12자 이상 비밀번호를 설정합니다. 예: IP 192.168.22.156, 마스크 255.255.255.0이면 대역은 192.168.22.0/24입니다. 실제 주소로 바꾸세요.

## 4. 방화벽과 서버 시작

서버 PC에서 03-Firewall.cmd를 우클릭 → 관리자 권한으로 실행합니다. 설정한 대역에서 접속 포트만 허용합니다. 02-Start.cmd를 실행하고 수업 중 창·전원을 켜 두세요. 종료는 Ctrl+C입니다. 전체 방화벽을 끄지 마세요.

## 5. 학생 접속 준비

설정 후 생성된 data/STUDENT_SETUP.zip만 학생에게 전달합니다. 학생과 서버 PC의 Windows 사용자마다 압축 해제 → 안의 Setup.cmd → 교수님이 준 원본을 확인한 뒤 YES → 교실 인증서 등록 승인 → Chrome 완전 종료 후 다시 실행합니다. 학생에게 전체 서버 폴더나 data/tls를 보내지 마세요. 학교 정책으로 설치가 막히면 담당자에게 요청하세요.

## 6. 가입·방·수업

Chrome에 서버 창의 HTTPS 주소를 입력하세요. 학생은 아이디·8자 이상 비밀번호·닉네임으로 가입하며 이메일 인증은 없습니다. 교수님은 최초 설정한 관리자 계정으로 로그인 → 채팅 사이트로 돌아가기 → 비밀번호 방 만들기를 합니다. 학생은 방을 선택해 비밀번호로 입장합니다. Enter 전송 / Shift+Enter 줄바꿈, 코드는 코드로 보내기를 선택합니다.

## 7. 화질과 언어

공유 PC에서 수업 글씨 선명하게를 누르면 원본 해상도·고화질·30fps를 선택합니다. 영상 부드럽게는 1080p·60fps·H.264 우선입니다. 실제 해상도·FPS는 PC와 네트워크에 따라 다릅니다. 학생은 전체 화면 또는 원본 크기로 보기를 사용할 수 있습니다. 오른쪽 위 언어 선택은 버튼·안내의 표시 언어를 바꾸며 선택은 브라우저에 저장됩니다.

## 8. 관리자·백업·업데이트

관리자만 회원 조회, 이용 정지/해제, 방 강제 퇴장과 방 삭제를 할 수 있습니다. 관리자 본인은 정지할 수 없습니다. 서버 종료 후 04-Backup.cmd로 백업하거나 05-Reset-Password.cmd로 비밀번호를 변경하세요. 업데이트는 서버 종료 → 새 ClassroomLive.jar 교체 → 기존 data와 java-path.txt 유지 → 서버 시작 → 모두 Ctrl+Shift+R입니다. 재시작하면 다시 로그인·입장해야 합니다.

## 연결이 안 되거나 흐리면

서버 전원·실제 IP·포트·허용 대역·인증서를 확인하세요. 채팅만 되면 Chrome을 새로고침하고 연결 진단을 복사하세요. 같은 건물도 VLAN/PC 간 차단으로 영상이 안 될 수 있어 학교 담당자의 허용이 필요합니다. IP 대역 제한만으로 유선과 같은 대역의 Wi-Fi를 구분할 수는 없습니다. 고화질을 7명에게 보내면 공유 PC 부하가 늘며, 1080p 원본을 1440p로 바꾼다고 세부 정보가 생기지는 않습니다.

## GitHub에 올리기

새 저장소에서 Add file → Upload files를 선택하고 압축을 푼 폴더 안의 파일·폴더를 올리세요. README.md가 최상위에 있어야 저장소 설명이 보입니다. 실행 후 생긴 data, 인증서 개인 키, 회원 데이터, 개인 java-path.txt는 올리지 마세요. 브라우저 업로드에서는 .gitignore만으로 제외되지 않습니다. Pages를 쓰려면 Settings → Pages → Deploy from a branch → main / (root)를 선택하면 이 다국어 안내 페이지가 열립니다.
