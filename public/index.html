공유 대기 중

공유자 설정입니다. 글씨 수업은 원본 해상도 · 30fps · 글자 선명도를 권장합니다.

실제 전송 품질은 화면 연결 후 표시됩니다.

선택한 화질과 프레임은 목표값이며, 화면 해상도·PC·네트워크에 따라 달라집니다.

화면이 안 보일 때 해결 방법
  1. 공유자와 시청자 모두 PC의 Chrome 또는 Edge를 사용하고 Ctrl+Shift+R로 새로고침하세요.
  2. 공유자는 공유 중지를 누른 뒤 화면 공유 시작을 다시 누르고, 실제 공유할 화면을 선택하세요.
  3. 글자나 코드 공유는 글자 선명도 우선, 1080p, 30fps부터 확인하세요.
  4. 같은 장소여도 PC 간 통신이 차단될 수 있습니다. 학교 담당자에게 브라우저 통신 허용과 PC 간 연결 차단 여부를 확인하세요. 방화벽 전체를 끌 필요는 없습니다.
  5. 이 버전은 교실 내부망 전용입니다. 화면만 안 보이면 PC 간 통신 차단 여부를 학교 담당자에게 확인하세요.

해결되지 않으면 공유자와 안 보이는 PC에서 각각 연결 진단 복사를 눌러 결과를 알려 주세요.
