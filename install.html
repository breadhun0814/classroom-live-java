서버를 운영할 PC와 수업에 참여할 학생 PC의 준비가 다릅니다. 내가 사용할 쪽을 선택해 확인하세요.

교수님·운영자 · 서버 PC 한 대

시작 파일 하나에서 이어갑니다.

Windows 실행용 ZIP 받기

개발 파일을 제외한 실행용 패키지입니다.
이미 압축을 풀었다면 아래 순서부터 진행하세요.

  1. 전체 압축을 풀고 Start-Classroom.cmd 실행

    ZIP 안에서 바로 실행하지 말고, 사용할 폴더에 전체 압축을 풉니다. Start-Classroom.cmd를 더블 클릭하면 설치된 Java 17+ JDK를 자동으로 찾습니다.

    Java가 없다면 화면에서 1을 선택해 Eclipse Temurin 21 JDK를 프로그램 폴더에만 준비할 수 있습니다. 최초 다운로드에는 인터넷이 필요하며 PATH·JAVA_HOME은 변경하지 않습니다.

  2. 처음 한 번, 교실 주소와 관리자 계정 설정

    감지한 IP와 허용 대역이 실제 교실 네트워크인지 확인합니다. 맞으면 Enter로 기본값을 사용하고, 포트와 관리자 아이디·비밀번호를 설정합니다. 이후 실행에서는 기존 설정을 재사용합니다.

    학생 접속을 위한 방화벽 요청에서 1을 선택하고 Windows 관리자 권한 창을 직접 승인합니다. 건너뛰었다면 학생 접속 전에 03-Firewall.cmd를 관리자 권한으로 실행하세요.

  3. 서버 시작 후, 학생 설치팩 전달

    서버 관리 앱이 열리며 서버가 자동 시작됩니다. 생성된 data/STUDENT_SETUP.zip만 학생에게 전달하세요. 서버 PC에서 브라우저를 사용할 사용자도 이 설치팩으로 교실 CA를 등록합니다.

    다음부터는 바탕화면의 Classroom Live 서버를 더블 클릭합니다. CMD 창 없이 서버가 자동 시작되고 관리 창만 열립니다. 수업 중에는 서버 PC와 관리 앱을 켜 둡니다.

수업 참여자 · 학생 PC

학생 PC에는 Java가 필요 없습니다.

이 페이지의 서버용 ZIP 대신, 교수님이 교실 서버에서 생성해 전달한 STUDENT_SETUP.zip을 받으세요. 학생 설치팩에는 해당 교실의 접속 주소와 공개 CA 인증서가 담깁니다.

  1. 설치팩 전체 압축 해제교수님이 제공한 원본인지 확인합니다.
  2. Setup.cmd 실행제공자와 인증서를 확인한 뒤 YES를 입력하고 교실 CA 등록을 승인합니다.
  3. 브라우저를 완전히 닫고 접속Chrome/Edge의 모든 창을 닫았다가 바탕화면의 Classroom Live LAN으로 접속합니다.

학교 정책으로 인증서 설치가 제한되면 담당자에게 요청하세요. 전체 서버 폴더나 data/tls는 학생에게 전달하지 않습니다.

설치 중 궁금할 수 있는 것

기존 서버를 업데이트할 때는 어떻게 하나요?

서버를 종료하고 기존 폴더를 백업한 뒤 새 실행 파일과 scripts 폴더를 복사합니다. 기존 data, .runtime, java-path.txt는 유지하세요. Start-Classroom.cmd는 기존 설정이 있으면 다시 만들지 않습니다.

Java를 이미 설치했는데 찾지 못한다면?

Java 17 이상과 javaw·keytool이 있는 JDK가 필요합니다. 프로그램 폴더의 java-path.txt에 실제 JDK 폴더를 한 줄로 지정할 수 있습니다. 별도로 지정한 경로가 잘못되면 자동으로 다른 Java로 바꾸지 않고 경로를 확인하도록 안내합니다. Java 8이나 keytool 없는 실행 환경은 사용할 수 없습니다.

인터넷이 없는 교실에서도 쓸 수 있나요?

Java가 이미 준비되어 있으면 수업 중 외부 서비스는 사용하지 않습니다. Java 자동 다운로드에는 인터넷이 필요하므로 미리 준비하거나 학교에서 제공하는 JDK 경로를 지정하세요.

채팅은 되는데 화면만 보이지 않는다면?

영상은 브라우저 사이로 직접 전달됩니다. 학교의 PC 간 통신 차단 정책을 확인하고, 실제 앱의 연결 진단을 참고하세요. 방화벽 전체를 끌 필요는 없습니다.
